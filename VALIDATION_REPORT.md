## Найденные и исправленные технические проблемы

1. Модель возвращала клипы короче 120 с; общий текст ошибки не помогал.
   Повторный запрос теперь содержит предыдущий JSON, фактическую длительность и
   допустимые окончания для выбранного начала. Неправильные интервалы не пропускаются.
2. Редакционная модель путала соседний контекст с содержимым клипа.
   В промпте разделены ДО / КЛИП / ПОСЛЕ; это уменьшает неоднозначность, но не гарантирует качество.
3. 8B-модель давала одинаковые высокие оценки при отборе и отклоняла все заявки при проверке.
   Для редакционного этапа добавлен отдельный выбор модели; испытана уже установленная 14B.
4. Для теста диапазон ASR и его кеш изолированы от полного транскрипта; таймкоды сохраняют
   положение в исходнике. При возвращении к UI диапазон анализа виден явно.
5. Перед GPU-ASR приложение освобождает VRAM своей выбранной LLM, не выгружая посторонние модели.
